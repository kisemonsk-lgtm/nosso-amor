# Nosso Amor ❤️

Site de contagem do namoro: tela de entrada, corações caindo, tempo juntos (anos, meses, dias, horas, minutos e segundos) e música do Spotify.

Tudo é personalizado dentro do próprio site, no botão **✎ Personalizar** — fica salvo no aparelho (localStorage).

- `index.html` — o site inteiro (HTML, CSS e JS num só arquivo).
- `.deploy.cjs` — publica a pasta no GitHub pela API (sem precisar de git instalado).
